1. INSTALLING BOOT DISK OPERATING SYSTEM
  2. Insert Macrium WinPE USB Disk into the USB port of the PC/Laptop
  3. Power on the PC/Laptop. When the boot screen flashes, enter the computer’s BIOS by pressing <F2> or <Del> button
  4. Inside BIOS screen, navigate to the BOOT Menu and change the BOOT ORDER or BOOT OPTION to USB in the first boot order

  1. From BIOS, SAVE & RESTART the computer.
  2. The Computer will now enter into the Macrium Reflect Windows PE environment.
  3. Choose the RESTORE Option. Navigate and Browse to the USB Drive partition with “Generic PC 2” image file inside and select this file to restore to the current <C:> Drive of the PC/Laptop
  4. Once the Restore process is completed, when prompted, Remove the USB drive FIRST and then choose the <Restart the PC> Option. The computer will now restart into Windows 10 normal OS environment.
  5. Upon logging into the computer using the admin password (strength88), log on to the Admin account.
  6. INSTALLING ZEROTIER VPN & ACCESSING NEUROS NETWORK
  7. Inside the Administrator Account <Download> Folder, you will find the “Zerotier One” installation file. Double click on this file to install the Zerotier VPN on to the computer
  8. In the taskbar area you will find the Zerotier icon . Right click and select <Join New Network>. Key in the Network name 93afae5963b7400c . Make sure you also select the option <Start UI at login> so that zerotier starts immediately upon user logon.
  9. After the previous step, the computer will be connected to the Neuros VPN Network.
  10. INSTALLING RUSTDESK SOFTWARE
  11. Inside the <Download> folder, you will also find the “rustdesk” installation file. Click on this file to install Rustdesk on the computer
  12. In the taskbar area, you will find the Rustdesk icon . Right click and <Open> to configure the settings. In the top right hand corner click on the 3 lines to access the Settings page:
  13. Click on the <Security> tab to access the Security settings. Click <unlock security settings>: to continue

  1. In the Password section, select the “Use Permanent Password” option to set the Admin/Team Manager-assigned password.
  2. You have completed the VPN and Rustdesk installation now. Record down the Desktop ID number into your notebook for filing and reference.
