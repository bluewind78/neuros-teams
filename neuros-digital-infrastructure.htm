Secure Access to Company’s IT Resources

 

1.      To allow all employees’ secure access to a suite of self-hosted server resources, Neuros APSC has leveraged on the use of Mesh VPN service, ZEROTIER. This allows all employees assigned with the appropriate IT resources with clients of varying platform types (Windows/Android/MacOS/Linux) are able to connect to all company server resources securely from any wireless or wired internet network globally through VPN tunnels established between their client machines/devices to APSC’s Main Server.

3.      Dashboard Control Panel could effectively monitor client uptime, last seen login usage data and IP/MAC address details of individual machines, which are useful details to network administrators to troubleshoot and benchmark network performance and resolve connectivity issues.

4.      By installing the ZEROTIER app set to run automatically upon login in all Neuros client machines, each machine will automatically login to NeurosNet Mesh VPN through the Network ID shown above.

5.      To add further security, each server resources, eg. Remote Monitoring, SMB File Server, DNS Filtering Service Modules, all require another layer of separate login credentials before they can be accessed.

DNS Filtering Services

 

12.   Another module that helps protect Neuros IT clients from being directed to malicious or dangerous websites when using web browsers are the DNS Filtering platform.

13.   By Using Pi-Hole DNS filter modules, each IT client asset can be configured to use this DNS module as their default DNS server before the IT asset (laptop/PC) is assigned to the Neuros employee.

14.   DNS queries that resolve to known malicious and dangerous websites will be blocked by this DNS module. The DNS block list can be easily updated with one click periodically to ensure it is constantly updated.

IT Resource Data Protection Policies

19.   Depending on the needs of the relevant departments, specific Data Protection Policies will be adopted as established by Management. For instance,

a.      Project Data pertaining to intellectual properties (IP) will be hosted fully on servers, accessible only by designated employees operating client systems approved to connect via Virtual Sessions, or by using the OPDM Team collaboration modules in Nextcloud Portal.

b.      Approved IT client hardware that have been restricted from sharing sensitive data, or uploading/downloading files to removable storage devices or untrusted cloud services such as google or Microsoft.

c.      Disable installation of third-party software by implementing UAC (User Account Control) in Windows platform laptops and desktop systems, to prevent malware proliferation.

d.      Disable addition of unauthorized email accounts into IT asset assigned to the employee

e.      Restrict access of working file storage paths to only designated locations, where designated locations data will be synced to backup server paths for protection or backup

f.       Specialized Department such as Service Teams will be accommodated lesser restrictions compared, for example, to Engineering and R&D teams.

 

 

 

 

 

Private Artificial Intelligence Server

20.   AI installed on the Neuros Main Server will process the input information and performs analysis tasks (thinking)

a.      User will input query (called Prompts) into the chatbox of the Ollama App installed on issued computer.

b.      AI will output the solution or desired results of the prompts for the task.

c.      AI will retain all information that users privately trained it with, with possibility to update with public information without leaking information online.

d.      AI can be accessed without server having internet access to commercial servers (offline)

e.      AI that is self-learning will be the source of the company’s Information Library and Archive and Knowledge Database of every system and equipment Neuros develops.
